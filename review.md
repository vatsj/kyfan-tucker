## Convention checks (brief §3a item 3)

- **Degree = number of vertices in a partial labeling.** `nsdeg.py` unknowns are `combinations(range(n), d) × product(labels, repeat=d)` — size-d partial labelings; `primal.py` columns likewise. Confirmed.
- **`pos_alt`** sorts the three labels by |·|, requires 3 distinct magnitudes and signs +,−,+. `tower.posalt` is the general-n version (distinct magnitudes, sign of i-th smallest = (−1)^i). Confirmed.
- **Free vertices** = `next(x for x in v if x) == 1` in every script. Confirmed.
- **Consistency equations.** Built at all levels 0..d−1 (not only d−1). Redundant, not wrong: a level-(d−1)-only system gives the same ranks and verdicts (507; 8400 F_2 / 8401 F_p). The package will build level d−1 only.
- **Antipodal extension** λ(−x) = −λ(x) is applied through `rep()` returning a sign, used consistently in `lab`, `forbidden`, `violating_pairs`, `act`.

## Findings that are not bugs in the scripts but should be recorded

1. **`primal.py` sanity check prints `False`** (see above). The action is correct; the check is wrong.
2. **Ky Fan lower bounds.** As originally reviewed, no script computed a Ky Fan *lower* bound: for S^2, S^3 it followed from Tucker's (#1, #3) by label restriction, and for n ≥ 4 row #5's "exactly n+1" was unsupported. **Resolved the same day**: the author supplied a separating functional (E over a box on one top simplex, S_1={+1,+2}, S_i={±i}; E kills all functions of ≤ n vertices, E(A+)=1) — proof in CLAUDE.md §2, checked line by line here, script `kyfan_lower.py` reproduces for m=3,4,5, and the naive negation-closed box gives E(A+)=0 as the proof predicts. Row #5 now stands with honest evidence; a new row #6 records Tucker's general-n status (≤ n+1; = n+1 for n=2,3; open beyond).
3. **Random-fresh verification of explicit certificates** (458 and 1286 monomials) is probabilistic. The *existence* of the d=3 Tucker certificate is exact via the inconsistent dual (`nsdeg.py`), but the Ky Fan one had no dual counterpart in the scripts. **Closed in this review**: the 458-monomial Tucker certificate was checked exhaustively on all 4^13 labelings (22 s), and the 1286-monomial Ky Fan certificate exactly by expanding both sides in the canonical one-hot basis (indicators avoiding the last label are linearly independent; Σc_α1_α and A+ + 1 have identical coefficient vectors, canonical support 705). Both exact checks go into the package tests.
4. `reproduce.sh` does not run `pseudo2.py`, `pseudo2c.py`, or `s3.py`, although results.md cites them. All three were run here and reproduce.
